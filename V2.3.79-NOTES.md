# AUREVIA COPILOT V2.3.79 — Validation du lot depuis Telegram

- Après confirmation technique M15, AUREVIA génère un code temporaire à usage unique (30 minutes) et l'envoie au chat Telegram privé lié au compte.
- L'utilisateur saisit manuellement le lot depuis Telegram avec `/lot CODE unique 0.05` ou `/lot CODE separate 0.05`.
- `unique` répartit le volume total entre les TP ; `separate` applique le lot saisi à chaque TP.
- La création est transactionnelle côté Supabase et réservée à `service_role` ; le serveur vérifie le propriétaire Telegram, le scénario confirmé, l'expiration, le profil broker (nom, compte, devise, levier) et la fiche instrument, le lot minimum, le pas et le maximum.
- Le groupe, les positions et le journal sont créés ensemble. Le code est invalidé après création.
- Aucun broker, MT5, API d'exécution ou ordre externe n'est appelé.
- Migration à appliquer : `supabase/migrations/20261113140000_telegram_scenario_lot_confirmation_v2379.sql`.
- Aucun déploiement ni migration de production effectué.
