# AUREVIA COPILOT V2.3.75 — TradingView comme source unique du calendrier

- TradingView est désormais l'unique source de tous les calendriers économiques visibles dans l'application.
- Les emplacements Marchés et Actualités utilisent le même widget TradingView (français, thème sombre, événements mondiaux).
- Suppression du calendrier structuré secondaire, de ses appels API côté interface, de ses filtres/tableaux et des libellés ambigus.
- Les sources macro/actualités utilisées par le moteur d'analyse restent distinctes du calendrier visuel ; aucun calendrier économique alternatif n'est affiché.
- Aucun déploiement, push GitHub, changement Supabase ou consommation de crédits Netlify.
