# AUREVIA COPILOT V2.3.77 — Fermeture hebdomadaire des marchés

- Ajout d’un calendrier hebdomadaire Forex et métaux basé sur `America/New_York` (dimanche 17:00 au vendredi 17:00, DST géré par Intl).
- Le bouton d’analyse est désactivé pendant la fermeture hebdomadaire et l’interface affiche « MARCHÉ FERMÉ ».
- `analysis.js` refuse de lancer une analyse locale lorsque le marché est fermé.
- Les fonctions serveur `market-data` et `ai-analysis` appliquent le même verrou `MARKET_CLOSED`, empêchant de contourner le blocage côté client.
- Les cryptomonnaies BTC/USD et ETH/USD restent analysables 24/7.
- Le module partagé est inclus dans le build web et le cache PWA est invalidé pour servir la nouvelle règle.
- Les suivis des positions déjà enregistrées ne sont pas désactivés par ce verrou d’analyse.

Limite : le calendrier gère la fermeture hebdomadaire standard, pas les jours fériés, fermetures exceptionnelles ou horaires particuliers des courtiers. Aucune publication/déploiement effectué.
