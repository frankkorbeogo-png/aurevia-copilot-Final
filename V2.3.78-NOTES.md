# AUREVIA COPILOT V2.3.78 — Configuration broker personnalisée

- Ajout d'un profil broker et compte par utilisateur : nom du broker, type de compte, devise et levier saisis manuellement.
- Ajout de spécifications distinctes par instrument : taille de contrat, lot minimum, pas, lot maximum facultatif, conversion vers devise du compte, commissions, marge par lot et valeur monétaire par unité de prix.
- Paramètres enregistrés dans `user_preferences.preferences.broker_settings` via Supabase RLS ; aucune migration SQL n'est requise.
- Les spécifications instrument sont reprises dans le formulaire de position et dans le calculateur de risque lorsqu'elles existent.
- Aucune valeur contractuelle, devise, levier, conversion ou marge n'est imposée par défaut ; un instrument sans fiche reste sans spécification préremplie.
- Aucun accès broker, MT5 ou envoi d'ordre externe n'est ajouté.
- Aucun déploiement ni modification de production effectué.

- Le levier, la devise, les minima/maxima et conversions ne sont pas préremplis par des valeurs supposées : l'utilisateur doit renseigner les données du compte et du broker.
- Le calculateur de risque et le formulaire de position récupèrent les spécifications enregistrées pour l'instrument sélectionné.
