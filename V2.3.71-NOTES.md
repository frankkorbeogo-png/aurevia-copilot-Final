# AUREVIA COPILOT V2.3.71 — diagnostic fournisseurs

## Corrections locales
- Cache OHLC local porté à 60 secondes pour limiter les appels répétés sur une même instance Netlify.
- Classification explicite des erreurs Twelve Data : clé refusée, quota (429), indisponibilité fournisseur et réponse inexploitable.
- Détection des réponses de quota Twelve Data même lorsque l'API les encapsule dans une réponse HTTP 200 avec `status: error`.
- Pas de repli sur un cache périmé après une erreur de quota ou d'authentification.
- Les erreurs Groq exposent maintenant un code diagnostique, le statut fournisseur et un détail limité, sans exposer la clé API.
- Les erreurs Groq 401/403, 400, 429, 5xx, timeout, réponse vide et JSON invalide sont distinguées.
- Ajout de logs serveur minimaux pour diagnostic, sans journaliser les jetons ni les données d'authentification.

## Limites
- Le cache mémoire Netlify est local à une instance et n'est pas partagé entre instances/cold starts.
- Ces corrections ne prouvent pas le bon fonctionnement des API distantes tant qu'un test réel autorisé n'a pas été exécuté sur une version déployée.
- Aucun déploiement, changement de variable Netlify, appel payant ou migration n'a été effectué.
